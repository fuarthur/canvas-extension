# Canvas 全局主题：设计规格

日期：2026-09-30。状态：会话设计已确认；本规格待用户审阅。

## 1. 目标与成功标准

在现有 Illinois Canvas 扩展的 Settings 中单独提供主题应用范围，让已有主题既能只改变规划 Tab，也能应用到整个 Canvas。用户要求保留颜色显示，并避免刷新时先显示浅色页面再切换深色。

成功标准：默认行为保持仅规划界面；启用全局后，同一 Canvas 站点的主要页面使用所选主题；关闭规划界面不会撤销全局主题；刷新和新开页面在正常存储可用时从首个可见内容帧显示已保存主题；课程、事件、状态、媒体和教学内容的颜色含义不变。

## 2. 设置交互

- 在外观设置中新增独立字段「主题应用范围 / Theme applies to」。选项为「仅规划 Tab / Planning tab only」和「整个 Canvas / Entire Canvas」。默认 `planner`；全局值为 `canvas`。
- 字段与主题选择并列，无需自定义主题才能使用。提示：「全局主题会调整 Canvas 界面；课程、事件和内容中的颜色保持原样。」
- 沿用现有 light、dark、forest、warm、system、custom 主题及四个自定义颜色，不新增第二套主题选择器。
- 改动范围自动保存，成功后立即生效；不刷新页面，不重新加载任务，不丢失规划草稿。保存期间禁用相应控件；失败恢复最后保存值并显示可重试错误。
- 从 `canvas` 切回 `planner`，移除扩展注入的全局主题，恢复 Canvas 原有样式。规划 Tab 继续使用已选主题。
- 主题及范围按 Canvas 域名和已核验账号保存。重置自定义颜色不改变应用范围；改变应用范围不改写主题颜色或其他设置。
- 英文和中文均提供对应标签、帮助文字和错误提示；控件沿用现有键盘、屏幕阅读器和窄屏布局约定。

## 3. 页面覆盖与颜色边界

覆盖 `https://canvas.illinois.edu/*` 的顶层 Canvas 应用页面，包括首页、课程、模块、作业、讨论、成绩、日历、收件箱和个人设置。排除 `/login`、`/logout`、`/oauth2` 及其子路径，以及 `/files/<id>/preview`、`/courses/<id>/files/<id>/preview` 和 `/media_objects_iframe/` 的独立预览；不向子框架注入，不修改第三方工具。课程 Files 列表本身仍属于覆盖范围。

采用组件适配：用 Canvas 界面变量和明确的原生界面选择器映射页面背景、导航、面板、列表、表格、普通按钮、输入框、菜单、对话框及交互状态。复用 `themePalette` 生成的颜色与对比度修正。全局适配样式必须限定在扩展自己的根标记下；关闭后不留视觉副作用。Canvas 品牌变量如需调整，应限定在所适配的界面组件内，不能从根节点继承进受保护的富文本、课程色标或状态组件。

以下内容具有保护边界：

- 课程卡片色带、课程圆点、日历色标，以及事件文字、边框和课程关联颜色保持原值。事件卡片保留适合这些原色的浅色背景，使深色模式下仍能辨认。不得把事件颜色统一为主题强调色。
- Canvas 成功、错误、警告、提交、评分、发布和未发布等状态的前景与背景配对保持原有语义；状态不能只依靠新的主题强调色区别。
- 图片、视频、SVG 插图、图表数据色、Canvas 绘图和文件预览不做滤镜或颜色替换。
- 教师富文本、代码和带显式颜色的教学内容不做后代元素通配覆盖。受保护富文本容器保留原有可读的浅色表面与文本配对，允许深色界面中的内容区域保持浅色。
- 原生日历上扩展自己的完成标记可复用主题中的 completed 配色，但不能改写相邻事件的原始颜色。

不使用整页 invert、hue-rotate、按 RGB 扫描替换、所有元素通配 `color/background !important` 或重写 Canvas 内容节点。没有明确适配的组件保持原样，不能为了覆盖率破坏内容颜色。

## 4. 模块与生命周期

新增独立全局主题模块，职责为生成适配 CSS、应用/撤销主题和维护页面级生命周期。它不依赖规划弹层是否打开，不读取任务和计划数据。

新增轻量 `document_start` 外观入口，在所有已授权 Canvas 顶层页面运行。入口只负责首帧主题恢复、Chrome 本地外观读取、账号核验和变化订阅。现有 `content.js`、原生日历桥和规划入口继续仅在日历页运行，避免在其他页面加载排程和任务界面代码。

构建脚本产出新入口；manifest 新增对应全站 `document_start` 内容脚本。权限保持 `storage` 和 `https://canvas.illinois.edu/*`，不扩大主机权限，不新增第三方请求或依赖。

设置视图继续由 `view.js` 协调账号和存储，主题范围使用独立存储接口。全局主题状态只通过外观存储变化同步，避免设置保存触发整个 Canvas 数据加载。

## 5. 存储与首次绘制

保留已有 `canvas-planner:<hostname>:<userId>:theme:v1` 主题记录。新增 `canvas-planner:<hostname>:<userId>:theme-scope:v1`，只接受字符串 `planner` 或 `canvas`。缺失或非法值回退 `planner`，不删除或改写原记录；非法值可在 Settings 中提示。

保留域名级 `appearance-account:v1`，用于查找上次核验账号的外观。读取时主题和范围取同一账号。旧版本的单账号主题迁移仍可恢复主题，范围默认 `planner`，不得自动开启全局主题。

为同步首帧恢复，在 Canvas 同源 localStorage 中新增 `canvas-planner:appearance-bootstrap:v1` 缓存。记录仅含 `schemaVersion: 1`、经过校验的主题和应用范围，不含账号 ID、任务、成绩、认证信息或任意 CSS。该缓存是可丢弃的外观副本；Chrome 存储是权威来源。

启动顺序：

1. `document_start` 同步读取并校验缓存。若缓存启用全局主题，在内容绘制前同步插入适配样式、设置根标记和页面底色；不得等待 Canvas API、规划 Tab 或页面加载完成。如果根节点尚未出现，仅观察它的首次创建并立即完成注入。
2. 有效缓存可立即显示页面；后台读取 Chrome 外观并核对、更新缓存。设置保存和跨页变化也更新缓存，因此正常刷新始终复用最新已保存配色。
3. 首次安装、升级或缓存损坏时，尚未确定范围的页面内容可暂缓显示，等待本地 Chrome 外观读取；等待上限固定为 250 毫秒。完成读取后先应用主题再释放内容。超时或不可用则释放为 Canvas 原样，绝不因主题失败一直隐藏页面。
4. 账号核验只读请求 `/api/v1/users/self/profile`，不阻塞首帧。成功后以该账号的外观替换启动提示并更新域名账号提示；此时无记录的账号使用默认范围 `planner`。请求失败保持已确定的外观，不加载或暴露其他账号的规划数据。

首帧外观提示只承载视觉设置，允许账号切换核验前短暂沿用上次使用的外观。正常同账号刷新不得出现浅色内容帧。无法读取任何本地设置且保护等待超时时，优先保证 Canvas 可用；不承诺浏览器导航自身的空白画面或存储彻底失效时仍恢复未知主题。

监听 Chrome 外观/账号提示变化和同源缓存变化，其他已打开页面无需刷新即可同步；监听系统颜色方案变化，仅 `system` 主题随之更新。异步读取带版本检查，迟到的启动、账号或保存结果不得覆盖较新的外观。BFCache 恢复时重新核对本地外观。页面销毁时清理监听和短期观察器。

## 6. 样式恢复、错误与性能

- 注入样式和根标记使用专属名称；主题切换只更新自己的样式。撤销移除自己的样式和标记，恢复任何临时修改的根样式原值，不清空 Canvas 自己的 style 或 class。
- 初始显示保护必须有独立释放路径和超时，读取错误、非法缓存、根节点延迟和销毁均不会让页面永久不可见。
- localStorage 禁止访问或写入失败不能导致设置保存失败；仍使用 Chrome 存储并通过启动保护完成正常读取。Chrome 保存失败则不把未保存设置传播给其他页面。
- 主要适配使用 CSS，自然覆盖 Canvas 后续加载的同类组件。不得持续遍历整页 DOM 或为每个节点添加样式；短期观察器仅处理首次根节点出现。
- 不覆盖页面布局、尺寸、可点击区域和原生键盘行为。普通界面文本与背景对比度至少 4.5:1，焦点与必要边界至少 3:1；课程和状态原色通过保留其可读背景配对来保护。

## 7. 验收与验证

自动化验证包含：范围默认、合法值与非法值回退；与已有主题存储兼容；账号和域名隔离；重置颜色保留范围；独立保存不影响其他设置；设置保存失败；自定义颜色校验；迟到读取与跨页保存竞争；缓存缺失、损坏、禁止访问和等待超时释放；切回 `planner` 完整撤销；系统主题变化；BFCache 恢复。

样式验证使用代表性原生组件样例，检查主题中性色生效，同时比较课程色标、事件文字/边框、状态提示、图表和显式富文本颜色在开关前后的实际 computed style。图片/框架内容不被滤镜或样式覆盖。验证普通文本和焦点的对比度。

真实浏览器验证至少覆盖 Calendar、Dashboard、课程/Modules、Assignment 和 Grades 的可访问页面；检查导航、表格、输入框、弹窗、悬停/选中状态及窄屏。Calendar 检查 Month、Week、Agenda 和侧栏课程颜色。

在 dark 和深色 custom 主题、全局范围下验证新开页、刷新和延迟 Canvas 数据加载的首帧；需要首帧/绘制时序证据，单张加载完成截图不能证明无闪屏。另检查 `system`、切换范围、跨页同步及关闭规划 Tab 后保持全局主题。

运行完整现有测试及构建；不修改与此功能无关的并行改动。交付包含设置、深色原生页面和受保护颜色的截图，以及防闪屏验证结果与实际覆盖范围。
