# Canvas 全局主题验收

日期：2026-09-30（America/Chicago）。本地分支：`feat/canvas-global-theme`，扩展版本 0.3.5。

## 功能

设置 → 外观中新增独立的“主题应用范围”。默认仅规划 Tab，选“整个 Canvas”后应用现有浅色、深色、森林、暖色、跟随系统或自定义主题。范围单独保存，不修改规划规则、语言或任务。关闭规划面板后全局外观继续生效，切回仅规划 Tab 会移除全局样式。

轻量入口在 document_start 同步恢复经过验证的外观缓存，Chrome 存储仍是权威来源；随后核对账号。缓存只含主题颜色和范围，不含账号、成绩、任务或认证数据。无可用缓存最多等待 250ms，超时或存储失败释放页面。登录/登出/OAuth、独立文件预览、媒体框架和所有子框架排除。权限和依赖未增加。

## 自动验证与审阅

- 初版全量测试：268/268 通过；生产构建成功；差异格式检查通过。
- 覆盖独立范围保存、损坏数据、账号隔离、旧外观迁移、缓存验证、同步启动、250ms 释放、迟到根节点、过期异步读取、跨页面同步、系统外观、账号切换、BFCache 和销毁。
- 初版样例中的事件、课程色块、状态、教学富文本、同名内容按钮/表格、媒体及绘图不被主题覆盖。相反亮度的自定义页面/卡片背景实际计算样式验证文字至少 4.5:1，焦点至少 3:1。
- 独立审阅提出两个重要问题：跨账号页面反复互写共享缓存、极端自定义颜色使用了错误背景的前景色。两者均先复现失败，再修复通过。缓存通知现在只触发权威设置核对，接收有效通知不再次发布；文字和焦点按所在界面的背景适配。没有延期的小问题。
- 实页发现 Dashboard 列表视图的固定浅色标题栏和日程文字遗漏，增加失败样例后修复，并复查实页标题、日期、普通链接、提示和操作按钮。课程标识和提交状态保持原色。
