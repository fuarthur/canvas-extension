Canvas Planning Calendar v0.3.8，适用于 Illinois Canvas 的 Chrome 扩展。

## 本次更新

- 精简标签导航、任务卡片和计划页，减少重复信息，将计划名称收进设置，突出日期范围、每日安排和未保存状态；改善自定义配色下的文字对比。
- 修复删除计划时的异步状态问题：等待删除回复期间切换或编辑其他计划，不会再被旧回复清空；保存中和重复确认也会受到保护。
- 修复同账号刷新或其他页面更新主题后，外观控件与实际配色、主题应用范围不一致的问题，并保留未保存的设置。
- 损坏的计划存档不会再阻断其他计划加载；过长的计划或日历日期范围会立即被拒绝，避免长时间卡顿。
- 工作量图切换到预计小时后，峰值日期按耗时重新计算。
- 修复夏令时回拨时，跨越重复小时的固定活动在周视图中显示过短的问题。

## 安装与升级

1. 下载 `canvas-planning-calendar-v0.3.8.zip` 并解压。
2. 新安装：打开 Chrome 的 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的解压文件夹。
3. 已安装：将新文件替换到原来加载的扩展目录，点击“重新加载”，再刷新已打开的 Canvas 页面。保留原安装，不要先卸载，以保留本地计划和设置。

本版权限、Canvas 主机范围和本地数据格式保持不变。本地完成标记不会向 Canvas 提交作业或更改其提交状态。
