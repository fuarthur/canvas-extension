Canvas Planning Calendar v0.3.6，适用于 Illinois Canvas 的 Chrome 扩展。

## 本次更新

- 任务估时输入在刷新或本地保存失败时继续保留，增加保存、重试和明确反馈；较早保存完成时不覆盖更新的输入。
- 取消加载当前筛选课程后，任务清单自动恢复“全部课程”，避免空白筛选框和假空清单。
- 删除计划后清除旧工作段编辑器，剩余计划继续正常显示；删除失败时保留当前编辑。
- 补齐规划弹窗的初始焦点、Tab/Shift+Tab 循环，以及关闭后返回入口的键盘操作。
- 提供仅使用虚构数据的本地体验环境，可模拟保存失败和 390px 窄屏。

## 安装与升级

1. 下载 `canvas-planning-calendar-v0.3.6.zip` 并解压。
2. 新安装：打开 Chrome 的 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的解压文件夹。
3. 已安装：将新文件替换到原来加载的扩展目录，点击“重新加载”，再刷新已打开的 Canvas 页面。保留原安装，不要先卸载，以保留本地计划和设置。

没有新增权限、数据迁移、遥测或外部数据传输。本地完成标记仍与 Canvas 作业提交状态区分。

## 验证与边界

- 341 项自动测试通过，零失败；生产构建及差异检查通过。
- 使用虚构数据实际验证桌面与 390px 窄屏的失败/重试、课程选择、计划删除和键盘焦点；检查了中英文及浅色/深色界面。
- 本轮浏览器验收使用隔离数据；真实账号下的扩展注入和后台通信不在本轮验收范围。
- 仍仅支持 `canvas.illinois.edu`；不包含无截止日期作业、不跨设备同步本地数据。自动排程可能因容量或搜索时限产生未安排任务。

安装包校验值见 `SHA256SUMS.txt`。
