Canvas Planning Calendar v0.3.9

## Changes

- Preserve calendar-month navigation and recover stale course filters and disappearing event editors.
- Reject invalid or ambiguous dates and account metadata; keep unresolved calendar activities as blocking facts instead of reporting a falsely complete schedule.
- Explain incomplete schedules and bounded-search limits, preserving existing local plans and settings.
- Include an isolated fictional-data demo, browser regression coverage, performance fixtures, and GitHub Actions checks.

## Install or upgrade

Download and extract `canvas-planning-calendar-v0.3.9.zip`. Load the folder containing `manifest.json` through Chrome extensions developer mode. For an existing installation, replace the files in its current folder, reload the extension, and refresh Canvas. Keep the existing installation to retain local data.

Permissions and the Illinois Canvas host scope are unchanged. Local completion does not submit assignments to Canvas.
