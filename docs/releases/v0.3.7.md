Canvas Planning Calendar v0.3.7，适用于 Illinois Canvas 的 Chrome 扩展。

## 本次更新

- 统一日历、任务、工作量、计划和设置的导航、间距与控件。参考 Telegram UI、Radix 和 shadcn/ui 的设计模式，保留轻量的原生界面和现有主题。
- 设置改为分组折叠，关闭时仍显示当前值；长说明收进“使用说明”，底部保留保存入口，输入时即时提示未保存的修改。验证失败会展开相关字段，切换加载模式或关闭提醒后也能修正无效值。
- 任务可在列表中直接完成或重新打开，并支持撤销；高级筛选可单独移除。改进操作后的键盘焦点、标签栏方向键导航和 Escape 关闭菜单的顺序。
- 计划页按当前状态突出保存、生成安排或接受预览；日期、容量和不常用筛选按需展开。改善中英文、浅色/深色主题和窄窗口布局。
- 新增可配置的桌面截止提醒，默认关闭，预设提前 2 小时。支持 1–5 轮提醒，跳过已提交或已完成的作业，并提供状态说明和测试提醒。
- 提醒记录按账号保存；后台处理离线、登录失效和休眠恢复，只补发尚未截止作业最近错过的一轮，避免重复提醒。

## 安装与升级

1. 下载 `canvas-planning-calendar-v0.3.7.zip` 并解压。
2. 新安装：打开 Chrome 的 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的解压文件夹。
3. 已安装：将新文件替换到原来加载的扩展目录，点击“重新加载”，再刷新已打开的 Canvas 页面。保留原安装，不要先卸载，以保留本地计划和设置。

本版新增 `alarms` 和 `notifications` 权限，用于后台截止提醒；Canvas 主机范围仍仅为 `https://canvas.illinois.edu/*`。提醒默认关闭，可在“设置 → 截止提醒”中自行开启。浏览器必须保持运行，系统休眠或通知设置可能延迟提醒。本地完成标记不会向 Canvas 提交作业或更改其提交状态。

## 验证与边界

- 合并后的版本通过 404 项自动测试，零失败；生产构建及差异检查通过。
- 界面检查使用虚构数据，覆盖桌面和 390px 窄窗口、中英文、浅色/深色主题、任务完成与撤销，以及隐藏设置的错误恢复。
- 真实账号下的系统通知投递、后台认证和 Chrome 重启尚未实测；自动化中的通知与后台环境为模拟，不能代替真实系统验证。
- 仍仅支持 `canvas.illinois.edu`；不包含无截止日期作业，不跨设备同步本地数据。自动排程可能因容量或搜索时限产生未安排任务。

安装包校验值见 `SHA256SUMS.txt`。
